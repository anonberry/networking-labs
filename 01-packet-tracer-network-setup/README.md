# Cisco Packet Tracer: Network Setup and LAN Configuration

## Project Overview

This project documents practical networking exercises completed using Cisco Packet Tracer. The activities cover basic network setup, IPv4 addressing, connecting network devices, and testing connectivity.

## Objectives

- Identify common network devices and their functions.
- Configure IPv4 addresses on end devices.
- Build a simple Local Area Network (LAN).
- Connect PCs to switches and interconnect the switches.
- Test and troubleshoot network connectivity.

## Tools Used

- Cisco Packet Tracer
- IPv4 addressing
- Ping utility
