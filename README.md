# Networking Labs

A hands-on portfolio documenting my journey in computer networking through practical labs, network simulations, configuration exercises, and troubleshooting.

## About This Repository

This repository contains my networking projects and lab exercises completed using Cisco Packet Tracer and other networking tools as I develop my understanding of network infrastructure, communication, and troubleshooting.

Each project includes documentation of its objectives, network setup, configurations, testing procedures, results, and lessons learned.

## Objectives

- Develop practical networking skills through hands-on exercises.
- Understand network devices, topologies, and communication.
- Practice IPv4 addressing and basic network configuration.
- Build and test Local Area Networks (LANs).
- Develop troubleshooting and problem-solving skills.
- Document my progress and technical knowledge.

## Tools and Technologies

- **Cisco Packet Tracer** — Network simulation and topology design.
- **IPv4 Addressing** — IP configuration and subnetting fundamentals.
- **Networking Devices** — PCs, switches, routers, and other simulated devices.
- **Network Testing** — Ping and basic connectivity verification.

Additional tools and technologies will be documented as I progress.
